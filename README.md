# Alex Wambua | Portfolio Website

A modern personal portfolio website built to showcase my skills, education, projects, services, and contact information as an IT student and web developer.

## About
This portfolio highlights my work in web development, software solutions, and IT-related skills. It includes:
- A homepage with intro and call-to-action
- About section with personal background
- Education and technical skills
- Services offered
- Featured projects
- Contact form and social links
